- 减少遮挡的HUD，护盾叠加条、透明实时排名、折叠任务、重新摆放雷达/FPS。
- H求救和雷达信号、中途加入补等级、全房间观战、观战聊天。
- 服务器磁盘持久化小队榜，分模式/难度；更新Docker数据卷配置。
- F8四种可交互工作界面；F9实际小窗；桌面版真正整窗隐藏/托盘恢复。
- 大厅/公共房间/榜单内的AI中转站推广位，指向用户指定域名；没有战斗广告弹窗。

`npm run test:abyss`自行启动独立服务并创建三个浏览器身份：

1. 房主创建无尽模式，名称/小队名/模式正确。
2. 观众从公开房间进入，观众发言在队员端出现，文本作为普通内容渲染。
3. 共享经验触发随机进化，三项独立卡片，选中后服务器效果生效。

5. 任务提示开场后自动折叠，点击可展开；排名背景为rgba(0,0,0,0)；状态条高度小于55px；护盾条有宽度。
6. Shift触发连续冲刺；倒地H信号到达队友，修复技能可以救援。

## 帧率与窗口

环境：Windows，本机RTX4060 Laptop/240Hz显示环境；真实WebGL绘制计数。

| 测试 | 实测平均FPS |
|---|---:|
| 普通2.0战斗，8秒 | 236.6 |
| 4玩家、150敌人、2倍DPI，6秒 | 236.2 |
| 同场景小窗+透明伤害榜，3秒 | 238.5 |
| Electron原生透明小窗，6秒 | 236.6 |
| 画中画主页面切后台 | 当次读数186 |

性能值是本机短时结果，不能承诺任意GPU、60Hz显示器、软件渲染或远程桌面达到144FPS。默认不锁60帧；可设置上限和均衡画质。隐藏后600ms采样的实际绘制为0帧。

原生窗口：F9前660×440，恢复后1422×962，再次F9回到660×440；无菜单、无系统标题栏，允许约1px系统DPI边界舍入。浏览器页面不能可靠隐藏整个浏览器窗口，整窗隐藏需桌面版，这是实际权限限制。
