# 4.0 — 夜班办公室奇谭 / Night Office Oddities

这是一次视觉世界与战斗呈现大改。品牌仍为带薪摸鱼，玩法、服务器权威同步、随机成长树、职业Q与基础普攻保留。

## 主要变化

- 墨紫、炭灰、纸白、黄铜、青绿和珊瑚红构成统一材质；大厅使用实际游戏预览，头像来自同一人物绘制系统。
- 八种基础人物体型、六个真实视图、十四关节；28职业有对应日常办公工具，投掷纸页/硬币/刀刃/鸭子等与职业相符。
- 七类办公室异变敌人：催办纸魔、爬行催办尸、附身碳粉机、文件柜魔像、无休晨会幽灵、超压咖啡机与绩效尸董，具备移动、起手、接触、受击、死亡动作。具体名称与数据以图鉴为准。
- 房间准备、职业卡、图鉴、指南、设置、结算、聊天、构筑与HUD采用同一视觉层级；F9仍为520×350中性小窗。
- 挥击特效采用明确的+X原始朝向与前方扇区；范围处决/冲击、护盾、治疗、召唤各有语义，武器接触方向与服务器判定一致。

## 修复原因

旧slash贴图向左而旋转代码以向右为基准，导致反向；蓄力期间p.angle仍变化，释放点又读取新角度；旧武器曲线在30%命中时偏向侧面。4.0分别在纹理/几何、权威待释放攻击和武器动作曲线修复，不只对截图加180度补丁。

参见[美术与动作](ART-4.0.md)、[验证数据](validation-4.0.json)、[性能](PERFORMANCE-4.0.md)。正式公开状态以GitHub v4.0.0 Release与对应Actions为准。保护主分支，PR与必需CI完成后正常合并。
