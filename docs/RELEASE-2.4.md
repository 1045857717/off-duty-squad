# 2.4 本地验收与设计说明

日期：2026-10-21（Asia/Shanghai）。服务版本2.4.0。启动/选卡阶段增加协议，更新服务会结束内存旧对局。

## 开局状态机

1. lobby：不生成/发送初始卡。房主免准备，其余真人在与出发按钮相同的底部操作栏准备；AI视为准备。房主可添加0–3位AI，真人+AI总数不超过4。
2. countdown：服务器计时3秒，数字/转环/文字动画提示。取消准备、房主取消、加入/离开/断线使倒计时结束并返回lobby；不泄露选卡。
3. draft：进入本局地图，无敌人、无模拟计时、玩家不可战斗。发放初始三选一；刷新恢复相同选项。AI自动选择，真人全部选完进入playing。房主可移除长时间未选/断线参与者。
4. playing：开始计时与刷怪，显示开场文字。晚加入者单独获得初始三选一与当前队伍待选强化，不暂停现有对局。

## 零件与E交互

全队共享零件：击杀、晶体、波次完成获得。遗物匣20零件换1次强化，军械缓存45换1次强化，血契祭坛35换2次强化并增加诅咒/生命代价，修复井免费补生命/护盾。修改了旧版大部分物件免费的逻辑，使资源有清晰用途。费用以实际设施cost为准。

HUD零件按钮可查看用途。E交互通道同步目标、实际进度、费用、资源不足、完成状态；对象周围有充能环。救援与继电终端也显示通道进度，完成后保留短暂结果。AI不自动消耗需要零件的设施，避免抢花共享资源。

## 战斗可读性与成长

- 默认空格冲刺，右键/R兼容，Shift选配；空格不兼做射击。物理按键/输入法组合守卫保留。
- 刃环常驻且位置跟随玩家，毒云/引力场/火焰扇区按服务器真实寿命显示；范围线对应实际判定半径，毒云持续伤害、引力持续拉扯。重叠近点重复释放刷新持续时间，避免无上限叠场。
- 缓存范围纹理：边界/装饰一次绘制为纹理，每帧旋转/缩放/透明度动画，避免每帧重建大量曲线；保留完整实际范围。Lv.4/8额外层次、卡框、角色气场，升级UI同步模块真实等级。
- 首领在屏外且满血时也有全局血条；同时最多展开2条，更多首领显示在场数量。暴击为金色辐射爆芒、粒子和大号「暴击」数字，普通命中样式保留。
- 人物手臂从微小抖动变成反向摆臂、手部位移和肩肘旋转，24步态连续播放；站立微动保留。
- 初始XP门槛110；以后100+32×等级^1.5，每8秒最多升1级。超出门槛的经验保留，HUD显示稳定倒计时。玩家长按数字不会连续选卡，服务端战斗中选择间隔至少0.45秒。

## 大厅、工作界面、合作位

首页实时公开房间列表，按模式和名称/码过滤，一键加入或观战；无底部重复入口。房间使用真实HTTP列表，自动刷新不锁住其他操作。

工作模式8种：原任务/看板/文档/报表，加Excel、邮件草稿、代码编辑、经营分析。进入方式可选上次/固定/随机，随机在每次F8进入时重选。Excel有功能区、单元格/公式栏、SUM与四则运算、工作表、CSV导出；采用受限解析器，不运行任意JS公式。邮件只保存本地草稿，不连接或发送真实邮件。

广告租赁位LOBBY-01/ARCHIVE-02/COMMUNITY-03位于大厅下方；ARCHIVE-02亦在榜单档案。按钮复制编号，失败时显示编号供手动复制，不虚报成功。原AI中转站链接保持。所有租赁位标注为广告，不遮挡战斗。

## 验证

56项核心逻辑/真实网络/地图/选卡/交互/持续范围/Excel公式测试通过。新增browser-launch.ts检查真实2玩家+2AI开局、倒计时取消、全员地图选卡屏障、刷新不重抽、空格冲刺、E进度/20零件扣费、XP结转、按键repeat、常驻范围/升级UI、暴击/屏外满血BOSS、工作模式固定/随机和Excel计算；0页面错误。生产构建/格式检查通过；死亡重开、模式切换、选卡继续移动/射击、公开房间观战/晚加入/救援/工作模式、小窗/画中画和原生窗口全部回归通过，原始2.4JSON随包附带。
