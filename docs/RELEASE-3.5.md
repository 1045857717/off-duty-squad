# 3.5.0 — 看得清血条，挥得出手感

日期：2026-10-22，Asia/Shanghai。首个 GitHub 正式发行版本；此前 3.4.0 为本地与源码准备里程碑，未创建公开发行标签。

## 人物与攻击

修复“关节在动但手臂看不出动作”的素材裁切根因：原统一矩形大多裁到画布透明外侧，真实袖子留在躯干里。现为 8 种基础体型、6 个绘制方向与 14 个部位建立真实解剖锚点和遮罩，共 672 个部位帧，仍对应 28 个职业与现有敌人模型，不宣称 28 套独立 3D 模型。

手臂与武器使用同一个当前攻击模块。蓄力、出手和收招连续过渡；握持点跟随真实手部矩阵，不再用固定远端位置挂武器。快速转身保持混合层透明度连续，武器跟随可见双层手部的位置插值；新鲜的排队模块保留完整起手，不从半个动作开始或直接跳过。短武器尖端轨迹支持近战与投掷，并限制为 95ms / 12 个点；减少动态效果时关闭。修复入场后重播过期攻击与旧 Q，敌人蓄力结束也保留连续动作。

## 血条与反馈

本人 82px、队友 68px 的头顶数字生命条，使用高对比轮廓；低血量用数字、颜色和状态文字共同提示。护盾有独立数值与条，金色近期损血延迟追随。底部生命区增加字号和条厚度，护盾数字合并在主行，保留紧凑高度。护盾破裂提供独立状态与音效；倒地提示根据是否还能救援显示。

## 工程与发布

继续使用 React / Phaser / Socket.IO；MIT 许可包含在源码、Docker 镜像与 Windows 包中。中英文 README、部署、备份、回退和版本发布文档随仓库提供。正式标签触发 GitHub Actions 构建 Windows x64 便携包与 Linux amd64 / arm64 镜像。实际远程结果在发行完成后记录。

## 验证

动作阶段回归已先复现失败，再修复通过。浏览器手感专项已逐项通过 16 种攻击的可见手臂变化、武器身份和握持点，覆盖双人准备/选卡/观战、生命/护盾、盾碎和 620px 小窗；0 页面错误。完整本地回归已通过 103 项游戏核心检查、5 项发布检查、TypeScript / Vite 与格式检查；浏览器覆盖新增手感专项、完整反馈、无尽联机及原画风场景，详见 [验收记录](validation-3.5.json)。容器与远程发行结果在执行后补充。

方案与 GitHub 来源见 [DESIGN-3.5](DESIGN-3.5.md)。性能仍受设备与场景影响，144 FPS 是目标选项，并非全场景保证；此前密集场景限制仍见 [3.4 性能记录](PERFORMANCE-3.4.md)。

## 本轮普通场景刷新率

1440×1000、DPR 2、Chromium 默认显示时钟（未关闭垂直同步），144 档实测 **141.64 FPS**；3 秒采样中游戏渲染数与浏览器 RAF 回调数一致。移动采样 58/58 帧均有位移，记录到 128 个不同步态相位。该样本说明当前环境下没有额外的游戏跳帧，不代表所有设备都能达到 144 FPS。原始结果见 [quality-3.5.json](quality-3.5.json)。本机当时另有原 3000 端口在线对局，未为测试关闭它。
