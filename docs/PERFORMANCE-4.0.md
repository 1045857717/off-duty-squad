# 4.0 性能验收

[English](PERFORMANCE-4.0.en.md) · [原始数据](performance-4.0.json)

测试跨2026-10-22至23进行，Windows/Chromium，1440×1000视口、DPR2。计数实际WebGL render调用，不读取目标设置当成绩。默认无头显示参考约59.88Hz；解除frame/vsync限制仅用于实验，生产界面尊重用户设置和显示环境。

最终压力主窗口采样6秒/1256帧，P95帧间隔8.50ms；小窗采样3秒。144档普通场景最后测量143.64FPS（RAF630.87，解除显示限制），默认显示约59.65FPS。存在明显样本波动，最终平均值通过不等于每帧均高于144，也不等于所有设备都锁144。保留全部完整阶段，不将最好样本当稳定值。这些阶段是诊断样本，不是严格控制的统计A/B。

## 压力条件

四人（1个真实浏览器+3个真实Socket.IO客户端），每人4模块，100个持续存活敌人，世界种子3900、DPR2；敌人以极高生命防止被清空。没有降低敌人数、分辨率、阈值或关节更新频率。它不是4台物理电脑或公网长期压力证明。

## 原生与画中画

GAME_URL明确指向版本4.0.0的3106预览，验收同时检查服务版本与playing阶段。当前原生显示环境144Hz、DPR1，520×350实际对局6秒采样856帧，约142.61FPS，RAF同为142.61；透明度0.43而UI opacity为1，置顶/穿透/托盘隐藏恢复/F9尺寸切换通过。较早DPR1.25环境测得57.82FPS，未捕获频率，不能和当前显示环境当作软件提速A/B。原生测试不是百怪压力测试。浏览器PiP背景约59FPS，属于单独的窗口调度条件，不将其称为144FPS。

## 优化实现

- 人物/敌人关节、28职业工具、16模块工具、22类投射物共用3840×4032图集。
- 弹体与尾迹一quad，六类粒子合并小图集；减少纹理切换与重复绘制。
- 生命条用斜角直接矩形/三角形，弧带按已知拓扑提交，避免通用Earcut反复求解。
- 移除8张未使用整身兼容纹理上传和重复侧栏榜单，保留游戏透明榜/F7。
- 小地图静态墙缓存为单SVGpath，真实弹丸在创建时保持同构basic字段。
- 保留15关节矩阵批处理、持续范围贴图缓存和全部关节每帧更新。

主角始终保留完整数字生命/护盾；健康队友采用42px细条，危急/倒地保留完整提示，精确队友HP始终在小队栏。此变更减少出生点重叠和重复文字，不降低角色关节、特效或分辨率。
