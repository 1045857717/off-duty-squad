# 2.5 成长树、难度与战报验收

日期：2026-10-21（Asia/Shanghai）。服务版本2.5.0。服务器状态与统计字段有更新，更新服务会结束内存旧对局。

## 成长规则

初始仍从12种攻击中随机三选一，进入地图后选择，职业Q固定。后续卡池从已习得攻击升级、已解锁关联分支、可用属性叶节点、职业核心中抽取。现有攻击低于Lv.8时保证有一个升级候选；每张卡显示成长路径。

新模块要求父攻击Lv.3、小队Lv.4、已持模块少于4。例：脉冲→霜晶/僚机/折射；雷电→引力/折射；刃环→旋刃/引力；引力→雷电/毒云。成长面板可查看每条前置与锁定原因。未解锁的卡不进随机池，服务端选卡时再次校验。

投射模块为脉冲、霜晶、回旋锯阵、僚机、寻星飞弹；只有持有其中之一才提供分裂弹/贯穿。游离刃环要求刃环Lv.2或旋刃Lv.3；尸爆要求烈焰/陨击Lv.3；终结者要求攻击Lv.4加暴击；吸血要求小队Lv.5加作战增幅Lv.2；战地纽带要求有队友且满足支援/护盾分支。封顶卡退出池。常规伤害/生命可继续成长，避免无尽后期卡池耗尽。

## 难度与经济

|---|---:|---:|
| 怪物基础生命 | 1× | 1.9× |
| 队伍耐久系数（1/2/3/4人） | 部分首领/数量成长 | 1/2/3/4×，计入AI |
| 敌人攻击人数系数 | 1× | 每多1人+15% |
| 刷怪间隔 | 原间隔 | 再除以人数平方根 |

| 晶体 / 波次零件 | 15 / 120 | 5 / 35 |

怪物血量使用基础×1.9×峰值队伍人数，再叠加波次/章节、难度和精英词缀。峰值人数只升不降，避免临时退队降低压力。晚加入使在场敌人按当前血量比例同步扩大生命，后续生成敌人也使用新系数。场上150敌人上限继续保留。

减少每图互动点（无尽最多5，远征最多7）、击杀与任务经验、章节/波次奖励、修复井恢复量和波间回血。血契祭坛现在一次高风险强化，仍有诅咒与生命代价。资源/回血不再形成早期滚雪球。

## 显示与状态

伤害账本使用有限两位小数精度累加；所有可见伤害/DPS/治疗/承伤使用整数格式，百分比也取整，消除浮点尾数。新增个人承伤、暴击、救援和零件贡献记录。实时榜使用火力总览、逐人贡献条、占比与整数DPS。

结果页展示模式、难度、峰值小队人数、积分、时间、波次/章节、击败数、等级、有效总伤害、逐人伤害/DPS/击败/治疗/救援、团队承伤/暴击、剩余资源和最终模块。全员失败时清除救援信号，求救按钮/横幅关闭。

E交互由服务器确认进度；显示采用逐帧插值和短窗口外推，仅用于画面，不提前发放奖励。新目标重置显示，松手停止外推，完成平滑到100%。

七种怪物重新绘制为曲线甲壳、材质明暗与多节肢体，32移动/16攻击/20死亡帧仍然预生成，保留不同体型与战斗职能。无需每帧重画模型。

首页仅一处创建入口、一个搜索；移除模式筛选按钮。工作侧栏每次默认收起为图标，支持展开；工作进入方式改为自绘主题下拉，支持键盘与焦点操作。

最后一位真人主动离开立即删除AI房间并使所有观战会话失效、通知返回大厅。若网络断开，暂停AI并隐藏公开列表，保留60秒重连身份；租期后同样清理。
