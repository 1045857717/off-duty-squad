# 工位发癫局 3.2 — 设计系统

用户方向：成熟比例、适当夸张的职场喜剧。随机爽刷、普通人和资本梗并存；人物细节必须用于实际战场。

## 用到的技能

- ui-ux-pro-max：先生成设计系统，再检查对比度、可见焦点、遮挡、触控尺寸、动画与动态减少。原安装脚本是失效的文本软链接；本次从官方仓库恢复搜索脚本/数据到work，执行结果存design-system/default/MASTER.md。
- game-development：GitHub社区仓库sickn33/agentic-awesome-skills中的web-games、2d-games、game-art。应用内容：DOM大厅与Phaser游戏画面分离、事件驱动状态、纹理预计算/对象池/剔除、统一素材比例、角色分层动画与全路径验证。继续使用当前测试通过的Phaser3.90。
- image2：明确使用gpt-image-2，经现有Codex配置的第三方服务转发CLI。没更换模型，也未切换官方端点。凭证只在子进程中使用，没有复制进项目。

## 配色和层级

大厅：暖奶油白#F3EFE5，纸面#FFFDF7，深墨#24363D，辅助文字#576C73；焦点/主操作橙#D76227，次操作青#276A73，准备状态绿#24734B。颜色同时有文字/勾选/边框解释，不只靠颜色判断。

战场：蓝灰地面、深色半透明HUD，温暖的伤害/成长重点色；较亮人物与场景明度分开。右侧伤害榜和底部HUD保留小体积。大厅公共聊天/小队准备聊天/对局边缘消息是三个独立布局。

## 输入与反馈

规则采用模式大卡+难度分段卡。AI人数采用按钮组。画质/刷新率/工作模式使用可键盘操作的同主题选择器，列表id由useId生成。T切换自动开火；输入框/输入法合成不触发，长按不连切。模态窗口隔离点击传播；鼠标关闭后不恢复鼠标焦点高亮，键盘打开仍恢复键盘焦点。技能成长详情收回后清除指针焦点。

## 美术管线

生成了两张4x4全身转面表（8种成熟比例角色×4视图），从白色背景原图做局部边缘连通抠图，保留白衣内部；每个模型规范为4×256×320透明PNG。28职业按职业族复用8个基础体型并绘制岗位小配件。肩/髋/头部独立枢轴生成8方向×24行走帧、24待机帧、16施法/救援帧；网络位置与渲染插值分开。不是28个独立3D网格或AI原生逐帧视频。

敌人复用相同绘制质感并加入打印机、咖啡桶、电话、巨饼等道具；保持32移动/16攻击/20倒地帧。对局角色从原来程序小人升级为实装图集，不以大厅肖像替代。

所有生成提示词及约束保存在docs/art-specs-3.2；原始PNG在public/art/generated，派生游戏素材在public/art/gameplay。WebP用于肖像、主视觉、叠加特效；运行时没有图像API依赖。
