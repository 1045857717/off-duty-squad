# 3.0 渲染与窗口验证

日期：2026-10-21；Windows，NVIDIA RTX 4060 Laptop，Chromium / Electron。数据来自本机短时测试。服务端模拟/广播频率不作为FPS，性能脚本计数实际WebGL render调用。

| 场景 | 实测 | 条件 |
|---|---:|---|
| 144档渲染上限 | 144.30 FPS | Chromium解除显示同步进行吞吐验证；连续移动56/56采样有位移 |
| 高密度战斗 | 147.47 FPS平均 | 4人、150怪、2倍DPI，每人16项满级模块；正常游戏上限是4模块，因此夹具超出正常构筑 |
| 同负载小窗/伤害榜 | 171.26 FPS平均 | 独立小视口与透明贡献榜 |
| 默认浏览器战斗 | 59.38 FPS | 当前默认显示链路约60Hz，帧间隔P95 17.2ms，隐藏后实际绘制0帧 |
| 原生透明660×440窗口 | 59.99 FPS | Electron，DPI1.25，画布825物理像素宽 |
| 同链路空白页 | 58.86 FPS | about:blank的requestAnimationFrame基线 |

高密度场景帧间隔P95为14.3ms，平均值通过144阈值，不代表每一帧都低于6.94ms。当前60Hz显示链路下，网页和原生端都只能展示约60帧；144档/解除同步压测与屏幕实际展示频率分开报告。游戏默认跟随浏览器帧循环，可选144上限；并没有将普通计时器或网络刷新数显示成144FPS。

144显示体验还需要目标电脑启用144Hz或更高刷新率、硬件加速及足够GPU性能。本版保留均衡画质/减少动态效果配置。不会由短时平均帧率推导所有机器都能稳定144。

## 本版的渲染处理

- 职业8方向×24步态、挥击/施法和蹲身救援各16姿态；纹理按当前真实职业惰性生成。工牌、衣摆、四肢、工具挥击与站立微动使用连续时间，渲染与服务器快照插值分开。
- 办公楼和园区使用分块缓存纹理，桌椅/机柜/停车线无需逐帧重画；天气使用少量线条。怪物32移动/16攻击/20死亡姿态预生成，离屏实体剔除。
- 持续范围场采用缓存纹理与少量可复用图元，命中/暴击/伤害数字按实际事件更新，保留实体、弹丸和拾取数量上限。
- 浏览器小窗交接时卸载主页面渲染器，隐藏后停止实际绘制；画中画主页面切后台仍正常绘制，本次约57FPS，恢复身份不重复占位。
- 原生端验证整体透明度通过真实窗口API生效（0.43），内部UI透明度为1，避免二次叠加；置顶、穿透、托盘隐藏/恢复和F9尺寸切换通过。
