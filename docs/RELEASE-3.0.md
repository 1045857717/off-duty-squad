## 美术与界面

整个游戏从工业虫群风改成成熟比例的办公灾变2.5D：纸白办公蓝大厅、应急橙标记、真实职业工牌；战场保留暗色高对比HUD，场景换成工位、茶水间、会议桌、机房、车库和雨夜园区。门禁卡、配电箱、撤离推车和感染主管取代旧的晶体/孢子母体叙事。

美术资产为项目内可编辑的Canvas绘制代码，在Phaser中预生成纹理/图集并使用WebGL渲染。本版使用可编辑的2.5D分层人物与场景图集。人类8方向×24步态，挥击/施法与蹲身救援各8方向×16姿态，角色图集按实际职业惰性生成；头发、眼镜、工装/衬衫/背包/工牌/衣摆/手臂和腿部有细节。感染者为人形轮廓，七类具备32移动/16攻击/20倒地帧、伸爪、抓咬、跛行与冲刺，保留不同体型。

F7、F2按钮直接显示「伤害排名」「游戏设置」和按键；小窗仍有悬浮提示。大厅公共聊天位于真实房间列表下，准备大厅消息层置于角色面板之上，避免消息存在却看不见。

## 装备、成长与环境

攻击池16种，其中四个新增非枪械模块：橡胶棍前方挥击击退，拖把环扫减速，管钳高伤眩晕，热咖啡持续灼烫扇区。原12种也改为办公/维修/消防/清洁器材；后续仍遵守成长树前置、Lv.4/8进化、最多4模块、无投射模块不出现弹丸专用卡。固定Q与累积升级保持。

打印机8秒诱饵引走附近感染者；喷淋10秒减速范围；档案柜和卷帘门产生短期真实碰撞，激活时会检查同伴位置，避免将人卡在墙内；卷帘门同时伤害/眩晕范围目标。机关E交互有进度与冷却，标签靠近时才显示。默认静音；打开音效后有脚步、工具挥击、打印机、拾取与治疗的合成提示。

噪声是实际状态：攻击/装置产生强度和寿命，噪声会衰减，较大动静提高追击密度；感染者可被打印机/手机引向目标点。尖啸感染者会召集增援。小队G集合，Shift+G危险，Alt+G补给，也可点HUD按钮，标记同步有冷却。

波间与章节休整开启8秒路线投票，真实连接的队员可投：补给恢复12HP并提供8零件；高风险路线增加压力与击杀零件；绕路降低刷怪并延后事件。章节必须完成装备选择与路线决策才继续；未投票超时按票数与固定平票顺序结算。

感染主管有护具减伤、追猎加速、召集增援三个阶段，2/3与1/3血触发；全局血条显示阶段，消息提示，召集阶段周期刷增援，实体上限仍150。
