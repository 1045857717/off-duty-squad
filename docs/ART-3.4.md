# 3.4 斜后视角与关节动画管线

本轮以两张3.2全身角色表作身份参考，经用户先前明确指定的Image2 CLI路径调用gpt-image-2编辑，生成新的16格斜后视角表。原图为纯白不透明背景，在本地处理边界连通背景、裁切和脚底对齐。保留全部原图和提示词，未切换模型。

- 新原图：public/art/generated/rear-quarters-v34.png。
- 完整最终规格：docs/art-specs-3.4/rear-quarter-spec.txt；in-image exact text为none。
- 输入参考：public/art/generated/gameplay-workers-a-v32.png、gameplay-workers-b-v32.png。
- 派生游戏素材：public/art/gameplay-v34/*.png，8种基础体型各1536×320（六列256×320）。前四列保留原前/前斜/侧/正背，后两列为真实斜后右/斜后左。开发员原图两个斜后方向重复，因此使用新生成斜后右的本地镜像形成斜后左，避免错误朝向。
- 实际映射：向右0→侧视列2；右下1→前斜列1；向下2→正面列0；左下3→镜像前斜；向左4→镜像侧视；左上5→斜后左列5；向上6→正背列3；右上7→斜后右列4。

新RigAtlas把8种基础模型、14个身体部位×6视角及职业/敌人道具合并成单一GPU纹理。肩肘腕、髋膝踝以父子关节计算，不以固定帧率强行切换整身图。为减少遍历开销，关节矩阵在数值层展开，渲染层为单层图像，保留肘膝与手脚的连接。75ms转向交叉淡入，移动距离驱动脚步，85ms起停过渡，起手/出手/收招衔接行走，头和胸有呼吸与微动。

玩家、7类敌人共享这条管线，区别是武器/职业动作、敌人道具、体型与阶段。敌人有身体蓄力、出手探身、受击后仰和约700ms连续倒地；非自爆敌人不绘制地面红圈。尚未声称生成28套独立模型或使用全3D网格；28职业继续基于8个基础体型与配件。

GitHub设计和引擎来源、模型与素材记录见3.4-skill-art-provenance.json。动画与联机检查见RELEASE-3.4.md。
