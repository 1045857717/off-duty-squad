# 3.3 — 茶水间、下班结算单和连续动作

日期：2026-10-21（Asia/Shanghai）。版本3.3.0。当前为本地验收版本，未发布远程服务器。

## 界面与内容

下方“夺回下班权档案”改为完整的六站行动指南。统一编号、任务目标、地点、难度、进度与查看入口；宽屏六列、中等宽度3×2、手机2×3。当前无尽模式只说明这是六章模式档案，不错误标出正在执行第一章。

游戏结束改为独立纸面下班结算单：成功/失败章、真实队伍与模式难度、下班绩效、时间/推进/击败/等级、整数贡献表、伤害占比、治疗/救援、表彰语、可切换队员的构筑。以应用根层Portal呈现，保留整窗透明度；背景不可点击、键盘焦点留在结算界面。房主可重整，所有人重新准备；玩家或观众均可返回大厅。离开的房主由真实队友接任。

准备区右侧优先放小队茶水间，不再在地图下方来回找。1366×768和1440×1000进行几何检查；手机使用可折叠固定茶水间，输入与内容在可视区内。公开大厅也把公共聊天移到右栏。房间或阶段改变重置到页面顶部。修复旧样式!important最小高度造成头像盖住队员名字的问题。

主视觉右侧文字放进不透明纸签，实测文字对比度7.67:1。所有招租位使用“联系QQ：1045857717”。广告仍只在大厅展示。

20句职场自嘲用于档案、开场、随机事件和表彰，包含“把尿喝白，把股炒红，把电充绿，把事办黄”“工资可以不涨，血条不能不满”“我不是执行力差，我是在等技能冷却”“小饼充饥，大饼清屏”等。不会增加战斗中心常驻遮挡。

## 工作模式

新增独立VS Code/IntelliJ IDEA风格界面：各自的标题栏、菜单、活动栏、项目树、页签、编辑器行号/语法着色/缩略图、终端和状态栏。真实可用的本地功能：切文件、每份文件分别自动保存、Tab缩进、Ctrl+S、Ctrl+F查找、关闭页签、隐藏项目树/终端、示例终端pwd/ls/git status/clear/help。不会执行系统命令；这是浏览器内工作模拟，并非安装VS Code或IDEA。设置支持固定IDE或随机进入。Excel、邮件与分析界面不再套“本周事项”通用大标题。

F10收起界面只显示工作台/继续，页签改为“项目协作工作台”；工作模式下收起也隐藏IDE。原生托盘菜单改用“收起窗口/继续工作/关闭工作区”。浏览器仍无法直接隐藏系统管理的整个浏览器窗口，原生客户端提供整窗隐藏。

## 角色根因与修复

原输入逻辑在附近存在怪物且关闭自动开火时，会禁止移动方向更新瞄准。真实浏览器复现向上走时服务端角度仍为0；修复后为-π/2。手动鼠标开火优先鼠标方向，自动开火才追踪怪物。

原角色虽有24帧走路图集，普通攻击却反复切到施法图集，覆盖下肢步态；后侧斜方向还共享近似后视。新ArticulatedActor以6个部位连续关节变换显示：移动距离驱动脚步，85ms起停过渡和85ms转向交叉淡入，开火/施法叠加上半身，救援压低姿态，冲刺保留连续位移和残影。后侧斜方向有独立肩/头偏移；保留牛马/鸭/背锅/实习等职业配件和呼吸、眨眼。继续复用既有8种生成基础模型，不宣称新生成28套模型。

本轮未新增Image2请求；保留3.2生成的gpt-image-2素材和全部原提示词。使用ui-ux-pro-max、game-development/web-games/game-art和systematic-debugging指导。

78项核心测试、TypeScript/Vite构建、格式检查通过；62组浏览器功能验收通过，页面错误0。新增测试使用2名玩家+1名观战者，对一个客户端WebSocket双向各增加75ms延迟，验证聊天、取消准备、全员初选屏障、真实移动、刷新重连不重复、结算重整、模式切换、房主离开继任和手机布局。还回归了中途加入、求救、伤害/成长、AI房间清理、弹窗/PiP和28职业技能。未进行跨物理机器或公网丢包/长时间耐久验证。

实际Windows便携EXE验证首次地址校验、保存配置、F9尺寸往返、透明度0.43、鼠标穿透、置顶开关、托盘隐藏恢复。包未代码签名。
