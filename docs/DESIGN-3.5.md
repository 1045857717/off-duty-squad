# 3.5 战斗可读性与人物动作

日期：2026-10-22。延续 Phaser 3.90、服务器权威模拟与现有绘制素材，不为追逐工具热度更换引擎。

## 真实根因

原人物上臂裁切范围位于画布外侧，但绘制人物的肩膀、肘部实际更靠近躯干；侧身图的对应区域大多透明。数字关节虽然旋转，画面中的袖子却留在躯干裁切里，造成“没有攻击动作”。此外，蓄力在动作进度 0.23 突然归零；武器采用最新网络模块，手臂仍播放上一条动作，产生错配。旧的动作检查只检查起止，遗漏了中间阶段。

## 修改

- 8 种基础体型、6 个绘制视角、14 个身体部位，共 672 帧，使用按朝向定义的肩肘腕与髋膝踝锚点重新裁切。手臂采用局部胶囊遮罩，躯干使用轮廓遮罩；侧身躯干去除原来烘焙在身体上的近侧手臂。
- 单张 2304×3360 图集包含全部关节帧与配件，尺寸低于 4096；只在初始化绘制一次，实际对局继续使用平铺关节矩阵，不增加逐帧 Canvas 裁切。
- 连续重叠的蓄力、触碰与收招曲线，保留高攻速队列；武器类型、角度与手臂采用同一条当前动作。握持点取真实手部矩阵。
- 武器尖端保留最多 12 个、95ms 内的轨迹点；近战和投掷有轨迹，射击与持续施法使用自己的效果。减少动态效果时不绘制轨迹。
- 新进入地图时不重播过期攻击或旧 Q；敌人的蓄力与出手也连续衔接，并在服务器快照之间继续插值。
- 本人 82px、队友 68px 的头顶生命条，数字、轮廓和危险颜色配合使用；护盾单独呈现。损血先即时减少，金色近期损失稍后追随。
- 底部生命区增加字号与生命条厚度，保持紧凑布局；护盾破裂有独立文字和音效，倒地提示依据能否救援显示。

## 方法与来源

使用现有 game-development / 2d-games / game-art / systematic-debugging / ui-ux-pro-max 技能。ui-ux-pro-max 随附检索脚本在本机未安装，因此直接依据其可读性、非颜色提示、动态效果与紧凑布局准则审查。

本次通过官方 GitHub API 核对的社区技能来源为 [sickn33/agentic-awesome-skills](https://github.com/sickn33/agentic-awesome-skills/blob/main/skills/game-development/SKILL.md)（原 antigravity-awesome-skills 地址会重定向），2026-10-22 观察到 48,263 Stars。其固定模拟、插值渲染、图集与对象复用原则用于本次实现。引擎来源为 [phaserjs/phaser](https://github.com/phaserjs/phaser)，同期观察到 40,525 Stars。计数会变化；没有宣称下载即自动改善画面。

## 验证策略

新增回归覆盖全部 16 种攻击的阶段连续性、旧快照、动作与武器身份、握持位置，以及生命/护盾和损血拖尾。浏览器逐项检查真实武器与手臂变化，并覆盖双人准备/选卡/观战与 620px 小窗。素材覆盖检查读取 672 个部位帧，所有帧均存在可见像素；四个远侧脚部透明占比较高，源于遮挡与裁切留白，未宣称各个视角均能看到所有肢体。

具体运行结果以 RELEASE-3.5.md 和浏览器报告为准。144 FPS 仍是目标档位，不承诺所有高密度场景固定 144。
