# 参考与取舍

选用现有Phaser骨骼/图集管线重做，兼顾既有玩法、输入与性能；舍弃换引擎（不会自动改善美术，迁移会破坏当前同步和窗口）和仅叠加CSS皮肤（不能修复动作与特效语义）。

参考：Steam官方《咒语旅团》页面；Bolt Blaster Games开发者在80.lv关于多人施法与大量敌人的访谈。GitHub pbakaus/impeccable（Apache2.0，本地已安装）用于替换视觉世界、去模板化与对比度/间距检查，非任何自动“去AI”滤镜。

截图根因记录见本轮findings。所有新游戏美术来自项目可编辑Canvas代码；当前工具无内置image_gen，不使用未经用户确认的CLI代替。保留旧资产作兼容，不将其宣称为新生成素材。
