# 2.2 本地验收记录

日期：2026-10-20（Asia/Shanghai）。服务健康版本：2.2.0。

## 玩法与画面

- 准备大厅仅使用服务器玩家数据，空席不补假人；房主、真人、AI、职业、异能、连接和准备状态分别可见。未准备/掉线的真人阻止开始；职业或规则变化使准备失效，观战不能设置准备。
- 远征：2560×1792封锁设施、多房间与走廊，六章收集/终端/护送/首领，解锁出口后集合撤离。
- 无尽：3072×2048开放灾变地形，不规则边界、崩塌障碍、陨坑与残破道路；按种子生成；倒计时结束或32秒后击杀配额达标进入下一波，在场首领必须击败，9秒补给，每5波首领。
- 无尽顶部、简报、底栏和雷达使用专用信息，不再显示六章远征目标。无尽不绘制撤离门，但保留补给/祭坛/宝箱和孢雾危险的展示。
- 七种怪物独立形状和大小。多足虫低生命、高移动速度、较低伤害；猎犬扑击；炮管射手散射；重甲大范围打击；幽魂漂浮弹幕；自爆囊体范围爆炸；大型多肢首领环形弹幕。每类32移动/16攻击/20死亡姿态；攻击序列与服务器同步，最多36个临时死亡模型。

## 界面与操作

- 整个应用一层透明度，含顶栏/大厅/战斗/设置；桌面端使用原生窗口透明度，和独立“窗口透明度”相乘，内部不重复淡化。浏览器不支持透出其他桌面窗口。
- 聊天发送成功立即收起并释放焦点，WASD继续；玩家ID绑定发言气泡，倒地H显示求救冒泡；屏外队友显示方向、距离与倒地状态。观战仍可发言并出现在透明聊天流。
- 基因进化可用时出现动态边缘提示，U展开/收起、1/2/3选择，继续移动和射击。
- 不拦截输入的开场文字入场后移出；左上任务进入、折叠、恢复动画；晶体从拾取位置飞入任务计数后递增、闪亮回弹。生命补给飞向血条，大经验飞向经验条。
- 底部原闪电零件图标改为工具图标并标注“零件”；Q旁图标为当前随机异能，“雷霆链路”是电弧连锁技能。

## 性能诊断

本轮默认浏览器约54FPS，空白页面RAF同样约54FPS。硬件渲染器为RTX4060Laptop的ANGLE/D3D11；多显示器/远程显示环境中默认刷新同步限制了可见帧率，不能把解除同步压测数值当成用户屏幕刷新率。

- 默认原生小窗实际绘制：54.27FPS，660×440；与当前空白页刷新一致。
- 解除显示同步的GPU绘制压测：4人、150怪、2×DPI最终约753.79FPS，小窗约1100.85FPS。测试只开启Chromium测试参数，不修改用户系统刷新率；这些是渲染吞吐，不是可见刷新。
- 144档真实绘制：143.99FPS；连续移动采样262/262帧有位移。
- 修复了FramePacer以取模丢弃整帧时间余量的问题；批量回调红测约58FPS，保留有上限的余量后回归通过。引擎使用单调时间，使重复/突跳的RAF时间戳不再把位移集中到单次更新。
- 原始结果见同目录2.2相关JSON。普通隐藏绘制次数、最终压力结果以附带验证文件为准。

实际可见144Hz仍需要显示器、GPU、浏览器硬件加速和当前显示链路支持。未更改用户的系统显示设置。
