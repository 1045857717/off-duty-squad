# 3.2 渲染性能验收

日期：2026-10-21。数据来自本机 Windows / NVIDIA RTX 4060 Laptop GPU、Chromium 和 Electron。它们是短时单机渲染样本，没有模拟公网延迟。性能脚本支持额外设置CPU_RATE观察限速表现；压力测试解除显示同步，故吞吐数字可能高于屏幕刷新率。

| 场景 | 实测 | 备注 |
|---|---:|---|
| 144档游戏画面 | 144.33 FPS | 58/58次动画采样均有移动；DPR 2，0控制台错误 |
| 默认显示链路 | 141.49 FPS | 8秒，16个实体，P95帧间隔7.4ms，0长任务，隐藏后0渲染帧 |
| Electron透明便携端 | 141.37 FPS | 实际打包EXE，约6秒、849帧，660px画布 |
| 密集战斗压力场景 | 194.33 FPS | 4玩家、150敌人、258弹幕、2x像素、每人16模块；约6秒，P95 10.5ms |
| 密集战斗小窗覆盖 | 221.47 FPS | 与上述同一压力场景 |

压力测试临时将模块数扩到16，以放大绘制负载；这是专用测试钩子，正式构筑仍限4模块。它证明本机该场景的渲染吞吐，并不等价于任意显卡都能持续144Hz。屏幕刷新率、功耗、透明合成、浏览器和网络情况都会影响实际体验。空白页面同机基线139.65FPS；本次默认链路没有之前历史版本约60Hz的瓶颈。

## 优化与动画

全身角色图集分层生成并按需缓存，逻辑更新与绘制插值分开。8方向各24帧走动/待机，施法与救援各16帧；离屏实体裁剪，普通攻击闪光保留45ms触发预算，特效合并一张图集并复用粒子池。新美术首轮压力样本140.4FPS，合批和闪光预算后样本145.71FPS；最终固定150怪的样本194.33FPS。它们不是相同运行时段的严格A/B对比，不能用差值声称统一加速比例。

最终压力夹具禁止怪物呼叫增援与随机环境事件，避免采样期间目标数量浮动；普通敌人动作、伤害、150个目标和满级模块仍运行。正式游戏的增援、事件与挑战不受测试夹具影响。

## 复测

```powershell
npm run check
npm run format:check
$env:PLAYWRIGHT_BROWSER='C:\path\to\chrome.exe'
npm run test:quality
npm run test:performance
$env:FULL_ARSENAL='1'
$env:ENEMY_COUNT='150'
$env:BENCHMARK_UNCAPPED='1'
npm run test:stress
```

浏览器测试需先运行3000端口服务器，并使用有硬件加速的真实Chromium。解除同步仅用于吞吐测试，不作为普通玩家设置。不要并行跑多个GPU压测。Electron实测直接启动最终ZIP内EXE，验证原生透明度0.43、660×440/1420×980往返、隐藏恢复与托盘；首次配置测试使用全新的临时用户目录。

本版原始结果见 `3.2-quality.json`、`3.2-performance.json`、`3.2-stress.json`、`3.2-display-baseline.json`、`3.2-native-verification.json` 和 `3.2-desktop-setup.json`。历史版本结果保留在对应版本文件。
