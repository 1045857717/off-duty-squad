# 3.4 设计与实现选择

目标是让玩家从角色动作看懂何时出手、从反馈知道为何受伤，并让大厅入口有明确用途。

界面延续成熟职场喜剧的纸面、墨色和暖橙，指南、图鉴、简报和排行榜使用相同层级。原档案入口集中为敌人/攻击/职业/履历；头像直达职业。简报使用独立Modal解决被准备层遮挡，房主队员管理使用明确确认步骤。

视觉反馈不依赖声音：身体蓄力、抬臂、亮口、弹丸轨迹和受击来源同时存在。遵循先前要求，只给自爆怪地面红圈。失败反馈以文字/图标、短促抖动和可用时的振动组合，减少动态模式关闭抖动。音效按事件独立节流，关键反馈不被脚步声压掉。

动作采用14部位骨架加真实斜后素材，起手/出手/收招与下肢步态分别计算，75ms转向过渡、85ms起停，敌人快照之间继续插值。关节层级在数值矩阵中展开，渲染层为平铺图像，统一GPU图集。保留Phaser3.90和权威Socket.IO服务器，未新增其他游戏引擎依赖。

在线数由服务端汇总匿名连接身份，AI排除，小窗继承身份去重。榜单为北京时间自然周期，以结束时间归档，存最近50000条，再按分数返回分区前50；继续使用单实例和JSON数据卷。

技术和素材来源见3.4-skill-art-provenance.json，完整验收和性能限制见RELEASE-3.4.md。所有功能检查通过，密集150怪场景的144FPS目标仍未达到，作为明确限制保留。
