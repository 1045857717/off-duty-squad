# 2.3 本地验收与玩法说明

日期：2026-10-20（Asia/Shanghai）。服务版本2.3.0。本次重构攻击来源与职业技能，准备/抽卡协议也有变化，更新服务会结束内存旧对局。

## 固定职业与累积随机构筑

| 角色 | 固定Q | 作用 |
|---|---|---|
| 斥候 | 散射脉冲 | 七枚高伤贯穿脉冲，7秒基础冷却 |
| 工程师 | 电磁过载 | 近身范围伤害、击退与眩晕，10秒 |
| 军医 | 生命脉冲 | 治疗并救起附近倒地队友，12秒 |
| 重装 | 守护力场 | 65护盾与短暂无敌，11秒 |

Q只随本人选择职业改变。随机卡添加/升级攻击、属性或职业核心，不会把Q换掉。角色选择说明、准备大厅、战斗HUD均使用实际职业配置。

初始攻击装备为空，无默认平射。准备大厅每人从12模块池抽取三张不同卡，选中一个Lv.1攻击模块后才可准备。AI明确自动抽取一个模块；真人包括房主必须手动准备。界面只保留一处「小队出发」。切职业/模式/难度后取消对应准备，断线也取消准备。房主仅可在大厅移除其他队员，移除时撤销旧会话，旧Token不能继续操作或恢复。

12种模块：星轨脉冲、雷暴导链、霜晶穿刺、回旋锯阵、卫星刃环、天火陨击、腐蚀孢群、蜂群僚机、焚风射流、寻星飞弹、坍缩奇点、折射晶束。分别采用定向射击、跳跃电弧、减速贯穿、扇形旋刃、自身刃环、锁定爆破、持续毒伤、交叉火力、前向火焰、追踪弹、聚怪引力、折射连击。每类独立冷却，可同时持有；Lv.1–8，每级提升伤害与冷却，Lv.4/8有规模跃升。每次后续随机抽卡保证一张可升级的已持有模块（若存在），其余候选继续随机。

联动：寒霜+烈焰使减速目标烈焰伤害+35%；雷电+引力对引力标记目标雷电伤害+30%；僚机+寻星飞弹使两者冷却缩短20%。构筑栏显示实际模块等级及联动说明。基础属性卡继续叠加并标注等级；职业核心提升Q强度并缩短冷却。

## 操作与反馈

- 默认R或鼠标右键冲刺，F2可启用Shift兼容；重复键不会连放冲刺。未改用户Windows/输入法快捷键。移动基于物理code，失焦/文本输入清空按键；组合输入确认Enter不发消息，组合期间不释放Q/冲刺/选卡。
- 权威hitSeq记录生命和护盾受击，护盾吸收也有蓝色闪光；生命红色、轻微后坐/镜头与边缘反馈；伤害数字带减号，低动效关闭镜头震动。
- 伤害榜文字不再额外低透明度，加入轻量半透明底色，无背景模糊、仍不拦截操作。
- 远征出口显示锁定条件或动态「撤离口已开启·全员集合」及撤离百分比；屏幕顶部有细条集合提示，角色附近保留方向指引。无尽不显示撤离门。
- 左上任务进入/折叠/恢复动画；晶体从实际世界拾取位置飞到任务计数，飞行结束加一并回弹。任务折叠后真正淡化，动画不覆盖后续opacity。

## 验证

49项核心测试通过，含12种攻击实际伤害、旧技能累积升级、不覆盖4角色Q、全员准备/踢人会话撤销、物理按键/输入法组合守卫、地图连通、伤害排名与任务推进。生产构建与格式检查通过。

新增tests/browser-arsenal.ts的8组真实浏览器验收：四职业说明；无装备选卡/全员准备/唯一出发/踢人；R和右键；升级与叠加；中文组合确认；蓝/红受击；12种模块绘制/伤害榜可读性；拾取飞入计数与出口提示。页面错误0。死亡重开、模式切换、选卡继续移动/射击、观战聊天/晚加入/救援/工作界面/小窗回归继续验证。

本轮4人各持12种Lv.8攻击、150怪、2×DPI，解除显示同步后实际渲染吞吐最终约241.89FPS；小窗约329.63FPS。这是GPU/渲染压力数据，不是屏幕可见刷新率。144档与默认显示链路实测见2.3相关JSON；设备/显示器/远程显示会影响最终FPS，不保证所有设备达到144Hz。

## 后续建议（尚未在本轮实现）

1. 选择路线和队伍投票：在波间选择高风险奖励房/补给/首领挑战，增加有意义的团队决策。
2. 角色协同技能：重装护住军医救援、工程师装置连接斥候弹幕，让配合比堆面板更重要。
3. 首领阶段机制：破甲/追猎/召唤阶段通过本体动作和音效区分，减少纯血量堆叠。
4. 固定种子挑战榜：按每日种子和难度比较小队成绩，方便同事公平竞速。
5. 更强的音效层次与无声替代反馈：攻击、护盾破裂、临近危险有可辨识信号，摸鱼静音时仍有细微视觉提示。
