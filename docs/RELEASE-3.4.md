# 3.4 — 看懂攻击，再快乐发癫

日期：2026-10-22（Asia/Shanghai）。版本3.4.0。本地与容器验收，尚未发布远程服务器。

## 角色、攻击和反馈

补齐8种基础体型的斜后右/斜后左素材，原来共用正背面导致的方向错觉已修复。实际八向图像映射、Image2规格和生成来源见ART-3.4.md。原图不透明白底，本地去背景；28职业仍基于8种体型，不是28套独立3D模型。

玩家与7类敌人共用14部位关节管线：肩肘腕、髋膝踝、头与躯干。通过父子关节矩阵保持连接，渲染层展开为平铺图像，避免逐关节嵌套容器的大量遍历。75ms转向淡入、85ms起停、移动距离驱动步态。敌人蓄力在服务器快照之间继续插值；死亡保留约700ms连续倒地。

16种攻击都有起手、出手、收招动作族，28个职业Q分别映射职业动作。修复高攻速不断重置动作、刚抬手就回开头的问题。服务器先发布42–95ms起手，再释放攻击模块，真正命中和视觉动作能对应。多武器同时触发时，以主动作结合各自特效表现，不通过切换整身动画冻结下肢。

敌人使用抬臂/举柜/压低重心/打印口亮起、头顶蓄力符号、出手探身和较亮弹丸轨迹。仅自爆怪使用地面红圈，其他敌人没有新增地面攻击范围提示。实际受击同时显示来源、方向、护盾反馈；中弹会有轻微后仰、闪色、伤害数字，失败与关键命中音效不再被脚步声的统一节流压掉。音效仍默认可关闭，减少动态效果可关闭相机抖动。

E失败由服务端给出原因，短促抖动、图标与文字提示，支持的设备额外振动；资源不够时不扣费。失败反馈有850ms限频。修复完成一处设施后，完成提示错误阻挡下一处设施的问题。

## 图鉴、简报与房间

任务简报原来低于准备大厅层级，被遮挡所以点击看似无反应；现改为独立可键盘操作的当前任务面板，展示真实波次/目标/队伍等级/零件与操作说明。

左侧“档案”扩展为“图鉴”：7敌人的基础参数、前摇、攻击方式、躲法；16攻击的Lv.1/4/8参数和关联成长分支；28职业固定Q详情和选择入口；保留本机个人履历。底部头像现在可打开职业图鉴。图鉴预览使用与游戏相同的模型和道具绘制函数。

队员卡移除悬浮X，新增管理按钮，确认/取消后才执行移出；实际服务端房主权限不变。指南重做为开局/战斗/成长/快捷键四章，统一纸面、墨色、暖橙；纠正旧说明把空格写成攻击的问题。

## 在线与公网

全站在线包括大厅、对局、观众，排除AI；匿名独立会话并非实名人数。500ms变更广播，小窗与主页面共享身份去重，回归验证4个连接/3个人身份只显示3。大厅也显示在线数，手机可见。

正式联机通过同一公网HTTPS域名；邀请链接按当前访问地址生成并清除小窗/哈希等参数，仅保留房间码。localhost只用于本地测试，不再要求同事打开局域网地址。PUBLIC_URL可配置服务器启动日志入口，Compose已传入。
