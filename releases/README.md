# Generated release artifacts

This directory is populated by the release workflow or `scripts/package-desktop.py`. Binary files are excluded from Git. Official images include the Windows portable ZIP; source-only builds may omit it, in which case the application reports the desktop download as unavailable.

- `offshift-desktop-win-x64.zip` — portable desktop client
- `desktop-release.json` — version, byte count and SHA-256

Download published artifacts from [GitHub Releases](https://github.com/1045857717/off-duty-squad/releases).
